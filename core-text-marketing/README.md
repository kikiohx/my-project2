# コア・テキスト マーケティング 第2版 — 読解パッケージ

『コア・テキスト マーケティング 第2版』（山本晶著）のスキャンデータ読解と、論文執筆への接続・外部理論比較・スライドの一式です。

## 重要: データ範囲について

Google Drive「コアテキストマーケティング」フォルダに現存するスキャンは**写真6枚＝ユニーク4ページ**（pp.176-177 第9章9.5 SP／pp.204-205 第10章10.4 ブランド・エクイティ。204-205は重複撮影あり）で、**1〜12章すべてのスキャンは含まれていません**。

- スキャンが存在する範囲 → 本文どおりの完全解説（太字・色付き語・図表）
- 本書の全体構成・論文接続 → Drive内「コア・テキストマーケティング研究提案」と公開書誌情報に基づく
- 未収録章 → 一般理論としての見取り図のみ（その旨を明記）

残りの章のスキャンを追加いただければ、同じ粒度で拡張します。
