## 1. SG 全体の設計意図（中西けんすけ 筆・新しいものが正）

### 最新かつ最も明確な言語化 — 2026-07-16 #ca-talk

TRANS は「次の時代をつくる人材輩出をするコミュニティプラットフォーム」であり、
そのために必要な組織モジュールの筆頭が:

> **1. 認識の拡大に向けたアプローチ:**
> **自己の認識を、個、集団、組織、社会に拡大させていくための枠組み**

同スレッド内で更に:

> 「**個と集団と組織と社会までの認識の境界を溶かすことで、全体性に対しての
> コンセプトデザインに取り組めるようにする**、というのは命題ではある」

→ これが「自己 → 他者 → 社会」というアークの一次ソース。
スレッド: https://transltd.slack.com/archives/C06L7HZT4FK/p1784186858208549?thread_ts=1784164202.335599&cid=C06L7HZT4FK

同スレッドでの SG の方法論に関する記述:
- 「SG でいつもナラティブを紐解きをしながら、自分の持っている性質の理解や、
  効果と逆効果の理解をしてもらっていたわけです」
- 「本当はもっとエクスペリエンスだけで理解できるような、**体験主義な手法**が必要だと思っている」
- 「ただ、おそらくそれはたった一回の体験で変容できるようなものではなく、
  ある程度の時間軸を過ごしながらトランジションしていくものになる」

### 発達理論の背骨 — 2026-08-05 #space-kenken

中西さんが Kegan の意識段階を段階2〜5まで通しで整理し直している
（主体 = それに「なっている」もの / 客体 = それを「見られる」もの）:
- 段階2 道具主義的知性: 他者は自分の目的を果たす手段。関係はすべて取引。
- 段階3 環境順応型知性: 主体 = 対人関係と所属集団。
- 段階4 自己主導型知性
- 段階5 自己変容型知性

### SG そのものの位置づけ — 2026-06-05 #labo-talk

> 「最近みんな忙しいと思っていて、それはすごい伝わっているんだけれど、
> **スタディグループは俺たちの本当に大切な文化**
> これがないと、ただの学生たちの集団がビジネスを頑張っているだけになってしまう。
> ここまで俺たちが特別な関係性でいられて、曲がりなりにも成果を出してきているのは、
> このシステムがあったからだということは絶対に忘れちゃいけない」

### 文化生成装置としての SG — 2024-07-23 #space-kenken

> 文化は、共通言語による「言語体系」、評価基準の設計による「価値判断」、
> 構造とルールによる「行動体系」から生まれると考えてて
> ・スタディグループで言語体系をつくり ・評価制度で価値体系を明確にする

### Notion Master ページ記載の目的

> 各メンバーの**認識力の向上とプロデューサーを生み出すための礎**を作る支援をする
> 学習プログラムをパッケージ化し、改善がかかり続けるシステムを構築する
> - SG は終わらなくてもよい / 狙わずに、**創発的な学習が発生する設計**が必要

### アークの読み解き（自己 → 他者 → 社会）

- **#1**: 全体の器・メカニズム提示（明示的に「その後の書籍の布石」と書かれている）
- **#2〜#4 = 自己**: 自意識の客体化 → 自分の偏り(Power/Love)の自覚 → 発達段階の理解と
  自己変容型のインストール
- **#5〜#7 = 他者 / チーム**: 弱さを見せ合える土壌(DDO) → 構造が行動を規定する(最小抵抗経路)
  → **チームが機能する条件を言語化する(今回)**
- **#8 = 組織 / 文化**: 機能するチームの積み重ねが文化になる
- **#9〜#11 = 社会 / 未来**: 自己変容のナラティブ → 出現する未来から導く(U理論) → ティール組織

### 今回(#7)の前後の接続

- **前から受け取るもの**: #5 の心理的安全性・DDO(個人ではなくチームとシステムで解決する)、
  #6 の「構造が行動を決める」という設計論の視点。
- **今回やること**: それを踏まえて「では**チームが機能している状態とは何か**」を Teaming
  (エドモンドソン: 学習としてのチームワーク) で言語化する。
- **次に渡すもの**: #8「文化とはなにか」への橋渡し。機能するチームのムード・学習が
  積み上がって文化になる、という接続。
